# Chapter 2: GF180MCU SerDes BFM (WIP)

[![Status:WIP](https://badgen.net/badge/Status/WIP/orange)](../README.md#chapters)

An open-source SerDes in **180 nm CMOS**, on GlobalFoundries [GF180MCU](https://github.com/google/gf180mcu-pdk), is in the works. [wafer.space](https://wafer.space), who run shuttles on this process, track that work and expect it in 6 to 9 months (as of October 2026).

The BFM will follow the silicon design. Nothing more is known yet: no ports, rates or features to model. This folder holds the place.
